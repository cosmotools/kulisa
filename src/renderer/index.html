Profiles

A profile is a separate browser profile, as in Chrome: its own cookies, storage, tabs and sign-ins. Sign in by hand in its pane; the agent in the terminal then uses it.

The agent works in this task's terminal: it writes the code and uses the profiles. If it is not on this computer yet, Kulisa installs it with its maker's installer. On its first start it asks you to sign in.
