# Contributing to Kulisa

Read [AGENTS.md](AGENTS.md) for development rules and [README.md](README.md) for setup.

- Test behavior changes; run `npm test` before a code PR.
- Write in English and state which of macOS, Windows and Linux you tested.
- By contributing, you confirm your right to submit the work under GPL-3.0-or-later
  ([LICENSING.md](docs/LICENSING.md)).
