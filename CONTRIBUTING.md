# Contributing to Kulisa

Thank you for helping. How Kulisa is built and the rules the code keeps: [CLAUDE.md](CLAUDE.md) (written for
the coding agent, and true for people too) and the docs it points to; how to run it and the tests: [README](README.md).

- Every behavior change comes with a test (`npm test` passes before a pull request).
- Everything in the repository is written in English.
- Kulisa runs on macOS, Windows and Linux: say on which you tried your change.
